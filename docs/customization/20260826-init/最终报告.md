## 2. 关键设计取舍

- **自定义源伪装成 `SourceType.RSS`**：上游 `ContentItem` 是 `extra="forbid"` 且
  `source_type` 是固定枚举，无法新增成员。自定义源统一标 `rss`，真实身份放
  `metadata`（`source_name` 会被上游 `_sub_source_label` 读取，报表仍显示真名）。
- **配图走「后处理插入」而非写进数据**：见坑点 §3.1。
- **图像 provider 抽象层**：`image_provider` 字段切换 `openai` / `dashscope`，
  新增模型只需加一个 `ImageProvider` 子类，illustrator / orchestrator 不动。
- **全链路静默降级**：二开任何一步失败都只记 warning、跳过，绝不中断主日报流程。
- **二开配置独立**：`data/custom.json`（结构化）+ 环境变量（密钥），不碰上游 `config.json`。

## 3. 踩过的坑（重点）

### 3.1 图片 Markdown 会被 summarizer 转义 —— 配图不能写进 item 数据
- **现象**：把 `![](url)` 写进 `ContentBlock.content`，渲染出来变成
  `\!\[\]\(url\)` 纯文本，图片不显示。
- **根因**：`summarizer._format_item` 对所有 block 内容调用 `_escape_markdown`。
- **解法**：改为**后处理**——等 `generate_summary` 产出完整 Markdown 字符串后，
  按每条报道前的 `<a id="item-xxx"></a>` 锚点定位，在标题行下方插入图片
  （此时不经过转义）。见 `hooks.insert_illustrations`。

### 3.2 anchor_id 如何与 summarizer 对齐
- **难点**：生图在扁平 `important_items` 上，插图要用 summary 里的锚点，
  而锚点由 `summarizer.build_view` 按 profile 分组 + 组内 index 算。
- **解法**：`illustrator.compute_anchor_map` 用**相同参数**复刻 `build_view`，
  以 **`id(item)` 对象身份**反查锚点（build_view 不复制 item，引用一致），
  绕开标题/URL 被转义变换的问题。用**契约测试**
  (`test_illustrator_anchor.py`) 锁死"算出的 anchor == summary 实际渲染的 id"，
  防上游改锚点规则时静默失效。

### 3.3 阿里云/千问 endpoint 报错 "messages must contain the word 'json'"
- **现象**：生成绘画提示词时 400，提示 messages 必须含 "json"。
- **根因**：上游 `OpenAIClient` 强制 `response_format=json_object`（整个管道要求
  返回 JSON），而阿里云规定用该模式时 prompt 必须出现 "json" 字样。
- **解法**：让绘画提示词也走 JSON——系统指令要求返回 `{"prompt": "..."}`，
  用上游 `ai.utils.parse_json_response` 解析。见 `illustrator.generate_prompt`。

### 3.4 阿里云文生图端点用错 + 多余的异步轮询（最大的坑）
- **现象**：图像 API POST 返回 400。
- **根因**：`qwen-image-3.0-pro` 属于**多模态生成**类，端点是
  `/services/aigc/multimodal-generation/generation`，而我最初误用了旧 wanx 的
  `/services/aigc/text2image/image-synthesis`；并且误信"HTTP 只支持异步"写了轮询，
  但 qwen-image-3.0 系列**支持同步调用**（旧的 `qwen-image`/`qwen-image-plus` 才只有异步）。
- **解法**：改为**同步调用** `multimodal-generation/generation`，从
  `output.choices[].message.content[].image` 取图片 URL（OSS 地址 **24h 过期**，
  即时下载落盘）。`image_size` 用 `宽*高` 格式（如 `1024*1024`）。
- **教训**：图像 API 这类外部依赖，**必须用真实 key 跑通再宣称修复**。
  为此加了 `scripts/verify_image.py` 做独立真实验证——已确认能出图（904KB PNG）。

## 5. 启动配置速查

1. `uv sync`，`cp data/config.example.json data/config.json`，`cp .env.example .env`
2. `data/config.json` 的 `ai` 段：`provider: openai`、`base_url`（你控制台地址）、
   `model: ZHIPU/GLM-5.3`、`api_key_env: DASHSCOPE_API_KEY`、`languages: ["zh"]`（生成中文）
3. `data/custom.json` 的 `illustrator`：`enabled: true`、`image_provider: dashscope`、
   `image_base_url: https://dashscope.aliyuncs.com/api/v1`、`image_model: qwen-image-3.0-pro`、
   `image_size: 1024*1024`
4. `.env`：`DASHSCOPE_API_KEY=...`、`HORIZON_IMAGE_API_KEY=...`（可与文本共用）
5. 先验证图像：`uv run python scripts/verify_image.py`
6. 再跑全量：`uv run horizon --hours 24`

> 上传（publisher）与自定义源默认 `enabled: false`，接入真实服务前保持关闭。
